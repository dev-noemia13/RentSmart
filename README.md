# RentSmart

Sistema de orçamento de locação desenvolvido em Python utilizando Programação Orientada a Objetos.

## Funcionalidades

- Cálculo de aluguel de apartamentos
- Cálculo de aluguel de casas
- Cálculo de aluguel de estúdios
- Aplicação de descontos
- Aplicação de adicionais
- Cálculo da taxa contratual
- Parcelamento da taxa contratual
- Geração de arquivo CSV com projeção dos 12 meses

## Estrutura do Projeto

main.py
imovel.py
contrato.py
utilitarios.py

## Requisitos

Python 3.x

## Execução

Abra o terminal na pasta do projeto e execute:

python main.py
